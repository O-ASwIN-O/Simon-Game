# Simon Game

A static Simon game built with HTML, CSS, and JavaScript.

## Vercel Deployment

This project is ready to deploy on Vercel as a static site.

1. Open the `Simon-Game` folder in Vercel.
2. Choose `Import Project` and select `Simon-Game` as the root.
3. Vercel will use `vercel.json` and deploy the static site.

No build command is required.

## Project files

- `index.html` — main page
- `styles.css` — styles
- `index.js` — game logic
- `sounds/` — audio assets
- `vercel.json` — Vercel static site config
